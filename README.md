# Phishing Email Analysis Portfolio

A blue-team portfolio demonstrating end-to-end phishing email investigation: header forensics, authentication analysis, IOC extraction, social engineering assessment, and campaign-level correlation across three real samples generated by the same phishing kit.

---

## What This Project Demonstrates

- **Header forensics**: SPF/DKIM/DMARC interpretation, From vs. envelope alignment, Message-ID forgery detection, MX/WHOIS validation
- **Tool-assisted analysis**: [PhishSage](https://github.com/...) header heuristics and link extraction, with manual verification of every automated finding
- **IOC extraction**: defanged URLs, sending IPs, envelope domains, tracking pixels, and kit-specific infrastructure fingerprints
- **Social engineering analysis**: pretext identification, urgency/threat tactics, authority impersonation, filter-evasion techniques
- **Campaign-level correlation**: proving three samples came from the same phishing kit despite targeting three different lure verticals
- **Detection translation**: converting findings into deployable gateway rules and SOC triage criteria
- **Simulation integration**: connecting real-world analysis back to phishing simulation design and awareness training
